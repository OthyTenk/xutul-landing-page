# Хөтөл (Xutul) - Бизнесийн Ухаалаг Туслах

Бизнес эрхлэгчдэд зориулсан бүртгэл хөтлөлт, борлуулалтын хяналт болон дижитал төлбөрийн нэгдсэн систем.

![Xutul Landing Page](https://github.com/OthyTenk/xutul-web/blob/main/screenshot/screenshot.png)

## 🚀 Төслийн тухай

**Хөтөл** нь жижиг, дунд бизнес эрхлэгчдэд өөрийн бизнесийг хаанаас ч, хэзээ ч удирдах боломжийг олгодог вэб болон гар утасны аппликейшн юм. Бид агуулахын бүртгэл, борлуулалтын орлого хянах болон дижитал төлбөр тооцооны системүүдийг нэг дор цогцлоосон эко системийг хөгжүүлж байна.

## ✨ Гол боломжууд

- 📱 **Нэмэлт төхөөрөмжгүй**: Зөвхөн утсаараа бүх бүртгэлийг хөтлөх боломжтой.
- 📦 **Агуулахын удирдлага**: Барааны үлдэгдэл, агуулахын хөдөлгөөнийг цаг алдалгүй хянах.
- 💰 **Орлого хяналт**: Борлуулалтын орлогоо минут тутамд тооцоолж, тайлан харах.
- 💳 **Дижитал төлбөр**: Qpay, Monpay зэрэг системүүдийг ашиглан төлбөр хүлээн авах.
- 📧 **Нэхэмжлэх илгээх**: Харилцагчийн имэйл хаягаар нэхэмжлэх шууд илгээх.
- 🔄 **Эко систем**: Бүх төрлийн банкууд болон төлбөрийн сувгуудтай холбогдоно.

## 🛠 Технологийн сан (Tech Stack)

Төслийг хамгийн орчин үеийн, хурдтай технологиуд ашиглан бүтээсэн:

- **Frontend Framework**: [React.js](https://reactjs.org/) (v18+)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animation**: [Framer Motion](https://www.framer.com/motion/)
- **Routing**: [React Router DOM](https://reactrouter.com/)
- **Icons**: [Heroicons](https://heroicons.com/)
- **Analytics**: Vercel Analytics & Google Analytics
- **Messaging**: EmailJS

## 📦 Суулгах заавар

Төслийг өөрийн локал орчинд ажиллуулах:

1. Репозиторыг хуулж авах (Clone):

   ```bash
   git clone https://github.com/OthyTenk/xutul-web.git
   ```

2. Төслийн хавтас руу орох:

   ```bash
   cd xweb
   ```

3. Хамааралтай сангуудыг суулгах (pnpm ашиглахыг зөвлөж байна):

   ```bash
   pnpm install
   ```

   _Эсвэл npm/yarn:_ `npm install`

4. Dev сервер асаах:
   ```bash
   npm run dev
   ```
